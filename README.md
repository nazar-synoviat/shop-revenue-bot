# Виручка магазину: Telegram-бот

Бот для швидкого обліку продажів у невеликому магазині чи кав'ярні. Продавець надсилає суму, а бот рахує виручку за день і тиждень та вивантажує звіт в Excel.

## Що вміє

- **Запис продажу одним повідомленням:** `350`, `1 200 кава`, `99,90`. Коментар необов'язковий.
- **📊 Сьогодні:** виручка, кількість продажів, середній чек.
- **📅 Тиждень:** виручка по днях за останні 7 днів і найкращий день.
- **📥 Excel:** файл з двома аркушами («Продажі» та «По днях»), гарно відформатований.
- **↩️ Скасувати останнє:** якщо помилилися із сумою.
- Кожен чат має свої дані, тому одного бота можуть використовувати кілька точок.

Суми розпізнаються в різних форматах: `1250`, `1 250,50`, `1250.5`, `200 грн`. Пробіл вважається роздільником тисяч лише перед трьома цифрами, тому `350 2 штуки` записується як 350 ₴ з коментарем «2 штуки».

## Технології

Python 3.12, [aiogram 3](https://docs.aiogram.dev/), SQLite, openpyxl, [uv](https://docs.astral.sh/uv/).

## Запуск

```bash
git clone https://github.com/nazar-synoviat/shop-revenue-bot.git
cd shop-revenue-bot
cp .env.example .env      # вставте токен від @BotFather
uv run shop-revenue-bot
```

## Структура

```
src/shop_revenue_bot/
├── __init__.py   # запуск бота і меню команд
├── bot.py        # обробники повідомлень і кнопок
├── db.py         # зберігання продажів у SQLite
├── report.py     # розбір сум, звіти, Excel
└── config.py     # налаштування з .env
```
